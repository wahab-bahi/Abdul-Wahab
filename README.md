## 🌟 Key Features

1. **Multi-Page Architecture**
   - **Home (`/`)**: High-impact split hero with real profile portrait, live availability status, core stats, tech marquee ribbon, and testimonials.
   - **About (`/about`)**: Story, Computer Science background, operating principles, and verified DigiSkills.pk credentials modal inspector.
   - **Services (`/services`)**: In-depth breakdown of WordPress, WooCommerce, and AI automation offerings, 5-step delivery process, **Interactive Project Scope & Timeline Estimator**, and an **Interactive Services FAQ accordion** with keyword search and category filtering.
   - **Projects (`/projects`)**: Case studies with category filtering (*Client Work, Collaborative, Browser Extensions, AI Automation*) and full screenshot galleries (e.g. *Prime Stay Management* & *Pugs Beauty*).
   - **Skills & Stack (`/skills`)**: Technical breakdown and an **Interactive Live Automation Pipeline Simulator** (WordPress Webhook → n8n → LLM → WhatsApp).
   - **Contact (`/contact`)**: Instant WhatsApp direct chat button, email copy button with toast feedback, project brief inquiry form, and FAQ accordion.

2. **Themes & Design**
   - Seamless **Light & Dark mode** with automatic persistence in `localStorage`.
   - Tailored typographic hierarchy using *Bricolage Grotesque*, *Plus Jakarta Sans*, and *JetBrains Mono*.

3. **Fluid Animations**
   - Cinematic page transition progress bar and spring settling.
   - Project card hover elevation, image zooming, and category active pill spring animations.

## 💻 Local Setup & Installation

Clone the repository and run locally:

```bash
# 1. Clone the repository
git clone https://github.com/wahab-bahi/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

## 📦 Building for Production

```bash
npm run build
npm run preview
```
